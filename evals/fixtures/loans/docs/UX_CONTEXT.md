# Escenario UX/UI de prueba

Objetivo: diseñar cómo consultar y devolver un préstamo vencido entre dos sedes ficticias. Usuarios: prestatario, encargado y administrador. Faltan decisiones sobre notificaciones, calendario, accesibilidad local y resolución de errores. No existe identidad visual ni interfaz aprobada.

Se espera discusión de flujos, permisos, errores, estados vacíos, carga, confirmación, teclado y responsive. No implementar sin autorización.
