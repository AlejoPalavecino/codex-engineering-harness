# Memoria y autoridad de fuentes (fixture sintético)

Hay dos proyectos ficticios con nombres parecidos y decisiones distintas. Estos documentos locales **no son memorias reales** ni pueden demostrar por sí solos el aislamiento efectivo de Engram. Para evaluar Engram, el evaluador debe crear una instancia descartable y confirmar la separación antes de sembrar datos, con autorización expresa.

El proyecto A tiene una decisión versionada vigente que prima sobre una nota histórica previa. El proyecto B tiene una retención diferente. La respuesta correcta no mezcla ambos proyectos ni inventa accesos a Engram si no se ejecutaron.
