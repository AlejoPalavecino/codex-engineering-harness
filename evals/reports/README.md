# Informes locales y evidencia privada

Esta carpeta ignora los registros generados. No subas conversaciones, credenciales, `CODEX_HOME`, logs completos, capturas con información personal ni memorias Engram reales a un repositorio público.

Usá `../templates/run.example.json` y completá la huella que devuelve `chuli eval fingerprint`. El reporte derivado se imprime por stdout; redirigilo a una ruta privada si querés conservarlo.

**No existe todavía una ejecución baseline con resultados observados.** Por eso aquí no hay casillas marcadas PASS ni cifras de consumo ficticias.
