# Chuli v2.1.4 · Una voz que enseña mientras trabaja

Esta release cambia cómo explica el orquestador, sin cambios en roles, modelos, permisos, instalador ni manifiestos:

- **Explicar para aprender:** el orquestador no da por sabido lo técnico. Primero cuenta en palabras cotidianas qué pasa y qué se rompe o se arriesga si no se atiende.
- **Errores con contexto:** ante un error, código o síntoma explica qué significa, sus causas posibles y cuál aplica según la evidencia, separando causa comprobada de hipótesis.
- **El porqué de cada decisión:** explica cómo se va a hacer el cambio y por qué de esa manera y no de otra.
- **Adaptación conservada:** si la persona muestra dominio del tema o pide ir directo al código, la profundidad se ajusta sin infantilizar.
- **Trazabilidad:** criterio VOZ-08 en la especificación de voz, escenario V-08 y comprobación estructural en `tests/validate_repository.py`.

Para actualizar el perfil desde v2.1.3, ejecutá `chuli --client <codex|claude|agy> update`, revisá el plan y repetí con `--apply`. Para actualizar el binario Manager, usá `go install github.com/AlejoPalavecino/codex-engineering-harness/v2/cmd/chuli@v2.1.4` o descargá los archivos de esta release verificando `SHA256SUMS.txt`. Para volver atrás en un perfil, revisá `chuli rollback` antes de aplicarlo.
