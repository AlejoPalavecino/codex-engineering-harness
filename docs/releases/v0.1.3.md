# Chuli v0.1.3 — Identidad y primer Manager TUI

- Identidad del producto **Chuli**, independiente del proveedor de IA.
- Aplicación de terminal `chuli` construida en Go con Bubble Tea v2.
- Instalación y actualización Codex desde checkout o release, con vista previa, confirmación y reutilización de scripts v0.1.2.
- Diagnóstico, rollback y visualización de versión instalada.
- CI con pruebas Go y compilaciones Windows, Linux y macOS; instalación funcional validada solo para Windows.
- Se conservan las rutas y configuraciones de v0.1.x.
- No incluye autoactualización del ejecutable, publicación de binarios firmados ni adaptadores Antigravity.
