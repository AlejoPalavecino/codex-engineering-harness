# Chuli v2.1.5 · Aviso cuando un estilo de salida pisa la voz de Chuli

Esta release suma un diagnóstico para Claude Code. No cambia roles, modelos, permisos, instalador ni manifiestos:

- **Aviso en doctor:** `chuli --client claude doctor` informa cuando `~/.claude/settings.json` tiene un `outputStyle` activo. Un output style se suma al system prompt y puede contradecir el tono CES de Chuli; por ejemplo, el estilo `Neutral` de Gentle AI prohíbe el voseo y los modismos regionales.
- **Sin tocar tu configuración:** el aviso es una advertencia no bloqueante y Chuli no modifica `outputStyle`. Si querés el tono de Chuli, quitá la clave o elegí el estilo Default.
- **Límites:** solo se revisa el `settings.json` del perfil, no los de proyecto ni `settings.local.json`. Cualquier estilo activo genera el aviso, aunque sea compatible con CES.
- **Trazabilidad:** pruebas unitarias en `tests/test_client_targets.py`, integración sobre un perfil temporal en `tests/windows-multiclient.ps1` y tablero `odd/tasks/claude-output-style-warning.md`.

Para actualizar el perfil desde v2.1.4, ejecutá `chuli --client <codex|claude|agy> update`, revisá el plan y repetí con `--apply`. Para actualizar el binario Manager, usá `go install github.com/AlejoPalavecino/codex-engineering-harness/v2/cmd/chuli@v2.1.5` o descargá los archivos de esta release verificando `SHA256SUMS.txt`. Para volver atrás en un perfil, revisá `chuli rollback` antes de aplicarlo.
