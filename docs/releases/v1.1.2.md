# Chuli 1.1.2 · Instalación con `go install` y mejoras de verificación

Esta versión habilita la instalación multiplataforma de Chuli Manager con un solo comando mediante Go e incorpora las correcciones de auditoría en validación Windows, resiliencia de rollback y publicación CI.

## Instalar con un comando (Windows, Linux y macOS)

Con Go 1.26+ instalado:

```sh
# Stable channel: the latest release (v1.1.2)
go install github.com/AlejoPalavecino/codex-engineering-harness/cmd/chuli@v1.1.2

# O siempre la última release estable etiquetada
go install github.com/AlejoPalavecino/codex-engineering-harness/cmd/chuli@latest
```

El ejecutable detecta la versión etiquetada desde los metadatos del módulo sin requerir `-ldflags`. Luego ejecutá `chuli` (requiere Python 3.11+ y PowerShell/`pwsh`) para descargar la última release del perfil, verificar su `SHA-256` e instalarlo en `CODEX_HOME`. Quienes no tengan Go pueden seguir usando `install-chuli-windows.ps1` o los paquetes portables de la release.

## Mejoras incluidas

- **Validación reproducible en Windows:** `.gitattributes` fija `eol=lf` para `tests/fixtures/**` y el job `windows-installer` de CI ejecuta `python tests/validate_repository.py`.
- **Reversión más resiliente en el instalador Windows:** `Restore-ManagerFile` reintenta hasta 5 veces (`40 ms`) ante `IO.IOException` transitorias al restaurar archivos y expone el motivo en la advertencia cuando la recuperación queda incompleta.
- **Workflow de publicación limpio:** `.github/workflows/release.yml` elimina el trigger residual `workflow_run` y el fallback `'1.0.0'`, operando únicamente por `workflow_dispatch`.

## Límites conocidos

- La resolución remota de `go install ...@v1.1.2` y `@latest` desde cualquier PC requiere que el tag `v1.1.2` esté publicado en GitHub; localmente se comprobó `go install ./cmd/chuli` sobre el módulo local y las pruebas unitarias de resolución de versión.
- Las pruebas en PowerShell 5.1 y PowerShell 7 validan perfiles temporales sin alterar el `PATH` permanente ni el `CODEX_HOME` del usuario.
