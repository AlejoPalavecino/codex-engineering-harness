# Chuli v2.1.2 · Tabla de roles de Codex

La tabla de AGENTS.md conserva el modelo y el esfuerzo del orquestador y de cada especialista al actualizar un perfil con el preset equilibrado. La instalación inicial también genera la tabla detallada.

Para actualizar desde v2.1.1, ejecutá `chuli --client codex update`, revisá el plan y repetí con `--apply`. Comprobá la instalación con `chuli --client codex doctor`. El formato del manifiesto y de los tableros sigue siendo compatible. Para restaurar el perfil anterior, revisá `chuli --client codex rollback` antes de aplicarlo.
