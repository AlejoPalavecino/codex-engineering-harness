# Chuli v2.0.3 · Presets recomendados por proveedor

En **Instalar → Equilibrado (recomendado)** podés elegir las siguientes asignaciones.

| Rol | Codex | Claude Code | AGY |
| --- | --- | --- | --- |
| Orquestación | GPT-6.2 Astra · medium | Opus · medium | Orchestrator (Argon) |
| Exploración | GPT-6.2 Sol · medium | Haiku · low | flash_lite |
| Implementación y diseño UX | GPT-6.2 Sol · medium | Sonnet · medium | pro |
| Arquitectura | GPT-6.2 Astra · high | Opus · high | pro |
| Pruebas | GPT-6.2 Sol · medium | Sonnet · medium | flash |
| Revisión | GPT-6.2 Sol · high | Opus · high | pro |

Claude Code resuelve los alias según tu proveedor. Cuando aplicás una selección explícita de modelos, Chuli quita de `settings.json` la variable `CLAUDE_CODE_SUBAGENT_MODEL` para que cada especialista pueda usar su modelo.

### Actualizar el Manager

Descargá el binario correspondiente a tu sistema o instalalo con Go.

```sh
go install github.com/AlejoPalavecino/codex-engineering-harness/v2/cmd/chuli@v2.0.3
```

Volvé a abrir Chuli y comprobá la versión con `chuli --version`. Podés consultar las asignaciones antes de aplicarlas con `chuli --client codex models list`, cambiando `codex` por `claude` o `agy` según corresponda.
