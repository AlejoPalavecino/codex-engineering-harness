# Codex Engineering Harness v0.1.1 — Seguimiento de tareas

Esta versión incorpora **Task Tracking Protocol (TTP v1.0)** sin añadir agentes, MCP ni una interfaz externa.

### Novedades

- Tareas persistentes por funcionalidad en `odd/tasks/<feature>.md` vinculadas a especificaciones/diseño aprobados.
- Estados PLANNED, READY, IN_PROGRESS, VERIFYING, BLOCKED, DONE y CANCELLED; DONE necesita evidencia.
- Seguimiento nativo con `[tools.update_plan] enabled = true` en la configuración de Codex cuando es compatible con el cliente.
- Resumen de tareas actuales, pendientes y bloqueadas, con recuperación entre sesiones.
- Script opcional `taskboard.py` (Python 3.11+) para validar dependencias, bloquear cambios de estado incorrectos y actualizar registros.
- Instalación y actualización de configuración con backups y rollback; pruebas automatizadas en Linux y Windows.

### Actualización

```powershell
git pull
.\scripts\install.ps1
.\scripts\install.ps1 -Apply
.\scripts\verify.ps1
```

El instalador preserva los MCP, Engram, hooks, plugins y otros agentes. Reabrí Codex para cargar la configuración y probá un trabajo R2 fuera de Plan Mode.

### Límites

- El aspecto del checklist de Codex Desktop depende de la versión y sesión: si la herramienta no está expuesta, el tablero Markdown sigue funcionando y puede mostrarse en el chat.
- No hay widget integrado propio, servidor MCP nuevo, tablero externo ni sincronización con GitHub Projects.
- Los scripts comprueban estructura, estados y dependencias; **no** certifican la autenticidad de las pruebas ejecutadas ni imponen el aislamiento de subagentes.
- La validación manual de la experiencia real de Codex Desktop está pendiente de feedback.
