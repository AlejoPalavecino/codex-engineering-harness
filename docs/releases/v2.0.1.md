# Chuli 2.0.1 · Asistente Guiado CRT, Actualizaciones, Versiones, Perfiles, MCPs Multi-Cliente y Fix AGY

Versión de mantenimiento y experiencia de usuario sobre `v2.0.0`: simplifica de punta a punta la instalación, actualización y gestión diaria del harness en **OpenAI Codex**, **Claude Code** y **AGY CLI**, e incluye correcciones importantes para el runtime de subagentes en AGY y compatibilidad con Windows PowerShell.

## Instalación directa recomendada (Go 1.26+)

```sh
# Stable channel: the latest release (v2.0.1)
go install github.com/AlejoPalavecino/codex-engineering-harness/v2/cmd/chuli@v2.0.1
```

## Lo nuevo en v2.0.1

### 1. Nuevo flujo guiado en la consola CRT (`internal/tui`)
- **Portada renovada con 6 accesos**: mantiene el banner pixel-art de la PC retro y el bloque `CHULI`, e incorpora **Instalar**, **Actualizar**, **Gestionar versiones**, **Perfiles de AI**, **MCPs** y **Skills**, junto con una alerta no bloqueante cuando hay una versión más nueva disponible.
- **Asistente paso a paso (`1/4` → `4/4`)**:
  - `1/4` Detección automática y selección de clientes (`Codex`, `Claude Code`, `AGY CLI`).
  - `2/4` Elección de **preset** o configuración **personalizada proveedor por proveedor y rol por rol**, navegable con flechas `↑`/`↓` y `Enter`.
  - `3/4` Pantalla de confirmación del plan antes de tocar el perfil.
  - `4/4` Instalación con animación CRT limpia que oculta el ruido de la salida cruda del script y cierra con un mensaje claro de éxito.

### 2. Actualizaciones, historial de versiones, perfiles, MCPs y skills
- **Actualizar**: consulta cancelable con `Esc`/`q` (sin bloqueos si falla o tarda la red) y resumen legible de novedades antes de aplicar.
- **Gestionar versiones**: listado de releases en caché local o remotas con cambio de versión y restauración (`rollback`).
- **Perfiles de AI**: almacenamiento en `~/.chuli/` de presets personalizados por proveedor para reutilizarlos entre instalaciones.
- **MCPs multi-cliente**: configuración y agregado de servidores MCP personalizados sincronizados para **Codex**, **Claude Code** y **AGY**.
- **Skills**: inventario interactivo para activar/desactivar skills gestionadas y registrar skills propias desde la TUI.

### 3. Correcciones de AGY y portabilidad PowerShell
- Uso de los tiers efectivos de subagentes AGY (`pro`, `flash`, `flash_lite`, `inherit`) en el catálogo de modelos y sincronización de `~/.gemini/antigravity-cli/settings.json` con respaldo y `rollback` seguros.
- Cálculo portátil de huellas `SHA-256` en PowerShell 5.1 y PowerShell 7+ usando .NET (`System.Security.Cryptography.SHA256`).
