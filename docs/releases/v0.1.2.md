# Codex Engineering Harness v0.1.2 — Estabilidad de instalación

Actualización de seguridad y mantenimiento que corrige tres defectos reproducidos en v0.1.1, sin alterar agentes, skills, CES, TTP ni memoria Engram.

## Correcciones

- **P1-1:** preparación y validación TOML antes de modificar Codex; encabezados comentados válidos y rechazo seguro de disposiciones incompatibles.
- **P1-2:** validación completa de backups, hashes y manifiesto previo antes de restaurar; no se inicia un rollback con respaldos incompletos.
- **P1-3:** informe de actualización por archivo, conservación de personalizaciones y reemplazo explícito mediante `-ReplaceCustomized`.
- **P2-1:** verificación independiente de la sintaxis TOML, valores administrados y modificaciones válidas en otras claves.

## Actualización

Requiere Windows PowerShell y **Python 3.11+** para validar TOML.

```powershell
git pull
.\scripts\install.ps1
.\scripts\install.ps1 -Apply
.\scripts\verify.ps1
```

Si deseás sobrescribir personalizaciones, primero revisá la propuesta y ejecutá `-Apply -ReplaceCustomized`. El respaldo se realiza automáticamente. Reiniciá Codex para cargar la configuración.

## Restricciones

No certifica permisos efectivos entre subagentes ni modelos realmente ejecutados. La validación de esos aspectos continúa en v0.2 y v0.3. La publicación es manual, requiere versión y SHA aprobados y CI satisfactorio.
