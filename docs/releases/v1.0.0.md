# Chuli 1.0.0 · Perfil personal para Codex

Instalá o actualizá Chuli con el Manager y seguí trabajando en Codex CLI o en el modo Codex local de la app de escritorio.

- Orquestación ODD y TDD proporcional, selección de herramientas según la tarea y seis especialistas con modelos configurables.
- 23 skills. Las cinco originales se combinan con 18 entradas de Gentle AI v4.4.0, con recursos compartidos, procedencia y licencias. Algunas entradas acompañan herramientas externas o tareas de contribución a Gentle AI.
- Paquete portable de perfil y sumas SHA-256. Un Manager nuevo puede instalar desde la release sin un clon manual, diagnosticar y revertir usando el paquete local.
- Se conserva el inventario y la recuperación de 0.2.1. El instalador trata las instrucciones personales, los recursos administrados y sus respaldos de forma diferenciada.

## Descarga

| Equipo | Archivo |
| --- | --- |
| Windows x64 | `chuli_v1.0.0_windows_amd64.zip` |
| Linux x64 | `chuli_v1.0.0_linux_amd64.tar.gz` |
| macOS ARM64 | `chuli_v1.0.0_darwin_arm64.tar.gz` |

Extraé el ejecutable, abrí la TUI y elegí instalar la última release. Necesitás Python 3.11+ y PowerShell. Verificá el resultado con `chuli doctor` y abrí una sesión nueva de Codex. El perfil es `chuli-profile-v1.0.0.zip`. Los cuatro archivos se verifican con `SHA256SUMS.txt`.
