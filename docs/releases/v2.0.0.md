# Chuli 2.0.0 · Soporte Multi-Cliente (Codex, Claude Code, AGY CLI), Modelos por Agente y Nueva TUI CRT

Chuli 2.0 amplía el harness a **OpenAI Codex**, **Claude Code** y **AGY CLI (Google Antigravity)** desde una única fuente canónica, permitiendo elegir presets rápidos o configurar qué modelo y nivel de esfuerzo usa cada uno de los 7 agentes (`orchestrator` + 6 especialistas).

## Instalar o actualizar con un comando

```sh
# Stable channel: the latest release (v2.0.0)
go install github.com/AlejoPalavecino/codex-engineering-harness/v2/cmd/chuli@v2.0.0

# O siempre la última release estable etiquetada
go install github.com/AlejoPalavecino/codex-engineering-harness/v2/cmd/chuli@latest
```

Abrí `chuli` para elegir cliente (`1:Codex`, `2:Claude`, `3:AGY` o `Tab`), explorar la pantalla **Modelos y presets** (`M`), ajustar modelos/esfuerzo rol por rol y aplicar con vista previa y verificación `SHA-256`.

## Catálogo de modelos y presets incluidos

- **OpenAI Codex (`codex`):** `gpt-6.1-sol`, `gpt-6.1-terra`, `gpt-6-luna`, `gpt-6-astra` (`codex-balanced`, `codex-astra-max`, `codex-fast`).
- **Claude Code (`claude`):** `claude-fable-5-2`, `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5`, `inherit` (`claude-balanced`, `claude-fable-max`, `claude-fast`).
- **AGY CLI (`agy`):** `orchestrator-argon`, `orchestrator-carbon`, `gemini-4-carbon`, `gemini-4-argon`, `gemini-4-hydrogen`, `inherit` (`agy-balanced`, `agy-carbon-max`, `agy-hydrogen-fast`).

## Qué adapta en cada cliente

| Cliente | Destino por defecto | Archivos administrados con backup y rollback |
| --- | --- | --- |
| **Codex** | `~/.codex` (`$CODEX_HOME`) | `AGENTS.md`, `config.toml`, `agents/*.toml`, `skills/**` y `harness/**` |
| **Claude Code** | `~/.claude` (`$CLAUDE_CONFIG_DIR`) | `CLAUDE.md`, `settings.json` (preservando UTF-8 BOM y permisos), `agents/*.md` (`disallowedTools` en roles de lectura), `skills/**` y `harness/**` |
| **AGY CLI** | `~/.gemini/config` (`$AGY_HOME`) | `plugins/chuli/plugin.json`, `plugins/chuli/rules/AGENTS.md`, `plugins/chuli/agents/*.md` (`subagent: true` + `tools`), `plugins/chuli/skills/**`, `settings.json` y `harness/**` |
