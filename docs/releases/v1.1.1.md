# Chuli 1.1.1 · Instalador Windows y comando chuli

Esta actualización incorpora la [PR #58](https://github.com/AlejoPalavecino/codex-engineering-harness/pull/58), que cierra el issue #57. Permite instalar el Manager por usuario para abrir su TUI escribiendo `chuli` desde cualquier carpeta de PowerShell.

## Instalar el comando en Windows

1. Descargá `install-chuli-windows.ps1` y `SHA256SUMS.txt` de esta release. Compará el SHA-256 del script con su entrada y revisá su contenido.
2. Desde la carpeta de descarga, ejecutá `./install-chuli-windows.ps1` en PowerShell para ver el destino y la versión.
3. Agregá `-Apply` para confirmar. El instalador descarga el Manager estable oficial, comprueba su SHA-256 y lo deja en `%LOCALAPPDATA%\Programs\Chuli`.
4. Ejecutá `chuli`. Si iniciaste el instalador desde otro proceso, cerrá y reabrí PowerShell para recibir el PATH actualizado.

No requiere administrador y conserva las entradas, variables y tipo de registro del PATH del usuario. Rechaza archivos/comandos ajenos o modificados, enlaces/junctions, destinos ambiguos, checksum incorrecto y versiones anteriores. Si falla una escritura, intenta recuperar la instalación anterior; conserva respaldos si no puede completar esa recuperación. Cerrá el Manager antes de reemplazarlo y evitá otros editores del PATH.

El instalador no modifica la política de ejecución de PowerShell, no instala dependencias ni aplica el perfil Codex. Desde la TUI elegís después si instalar o actualizar ese perfil. La vista previa no instala archivos ni cambia el PATH.

La comparación SHA-256 comprueba integridad respecto de la release oficial, no una firma independiente del editor. Los cinco archivos provienen del CI del SHA exacto de main; el publicador verifica nombres, versión, archivos, fuente del instalador y tag antes de publicar.

## Actualizar una instalación existente

La TUI actual puede actualizar el perfil a v1.1.1. Para actualizar el ejecutable del Manager, cerralo y usá el instalador o descargá el nuevo paquete portable. La TUI todavía no reemplaza su propio ejecutable. Después de actualizar el perfil, abrí una sesión nueva de Codex.

## Evidencia y límites

Las pruebas aisladas del instalador cubren vista previa, repetición sin duplicar PATH, preservación de archivos, ZIP/checksum inválidos, rutas parcialmente relativas, separadores de PATH y recuperación ante un fallo simulado. Se ejecutan en PowerShell 7 y Windows PowerShell 5.1. La descarga real y `chuli version` se comprueban sobre una carpeta y PATH de proceso temporales.

El usuario eligió conservar su PC sin instalación permanente: no se probó la escritura de su PATH de usuario. Esa rama fue revisada estáticamente. No se utilizaron cuentas de proveedores ni memorias personales. El registro de entrega, CI, publicación y comprobaciones finales queda en `odd/tasks/release-v1.1.1.md`.
