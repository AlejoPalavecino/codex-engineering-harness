# Chuli v2.1.3 · Catálogo único, CI POSIX y guardrails de paquete

Esta release consolida mejoras de mantenimiento, confiabilidad y paridad en el Manager y el pipeline de verificación sin cambios incompatibles en perfiles ni manifiestos:

- **Catálogo único de modelos:** el binario Go embebe directamente `config/models.json` como fuente única compartida con `scripts/client_targets.py`, evitando deriva entre clientes, roles y presets.
- **Validación funcional POSIX en CI:** `scripts/profile.ps1` contempla los alias del sistema `/tmp` y `/var` en macOS (compatible con PowerShell 5.1 y 7) y el CI ejecuta pruebas de instalación, verificación y rollback con `pwsh` en Ubuntu y macOS.
- **Guardrails de presupuesto del paquete:** `scripts/verify_release.py` comprueba tamaño comprimido, tamaño expandido, tamaño por entrada y cantidad de archivos del perfil contra los límites de `internal/manager/archive.go`, conservando intacto el pin upstream de `diagram-design`.
- **Mantenibilidad y pruebas:** estado de `internal/tui` organizado por dominio con `versions.go` separado, soporte de `go test -short ./...` en `internal/manager`, y `docs/ROADMAP.md` actualizado.

Para actualizar el perfil desde v2.1.2, ejecutá `chuli --client <codex|claude|agy> update`, revisá el plan y repetí con `--apply`. Para actualizar el binario Manager, usá `go install github.com/AlejoPalavecino/codex-engineering-harness/v2/cmd/chuli@v2.1.3` o descargá los archivos de esta release verificando `SHA256SUMS.txt`. Para volver atrás en un perfil, revisá `chuli rollback` antes de aplicarlo.
