# Chuli v2.1.0 · Trazabilidad y verificación del roadmap

Antes de pasar a tareas, Chuli señala qué falta decidir para que un criterio de aceptación tenga una prueba observable. Cuando cambia un archivo, el tablero permite consultar los requisitos, las tareas y las pruebas vinculadas. También se pueden registrar y comprobar decisiones de arquitectura.

Los tableros existentes conservan su formato. Los equipos que adoptan los nuevos campos pueden seguir el impacto de sus cambios y detectar evidencia desactualizada en una tarea o en sus dependencias. Codex, Claude Code y AGY reciben el flujo de Git y GitHub. El perfil incluye guías para revisar riesgos de seguridad, operar el harness y evaluar su comportamiento.

## Instalación y actualización

Descargá el Manager de tu plataforma o ejecutá:

```sh
go install github.com/AlejoPalavecino/codex-engineering-harness/v2/cmd/chuli@v2.1.0
```

Para instalar el perfil, ejecutá `chuli --client codex install`, revisá el destino y repetí con `--apply`. Si ya usás v2.0.3, usá `update` en lugar de `install`. Para Claude Code o AGY, elegí `claude` o `agy`. Comprobá el perfil con `doctor`. Para restaurar el perfil anterior, revisá `rollback` y aplicalo con `--apply`. Para volver al Manager anterior, descargá su binario de la release v2.0.3.

La publicación usa el candidato de CI identificado por commit, ejecución y artefacto. Las sumas de los archivos distribuidos están en `SHA256SUMS.txt`.
