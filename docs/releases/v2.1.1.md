# Chuli v2.1.1 · Recursos por cliente

TTP y la skill de especificación indican dónde encontrar la plantilla, el protocolo y el validador en el perfil activo de Codex, Claude Code o Antigravity. En AGY, la entrada de diagram-design cabe en el límite de carga del cliente y enlaza a la guía completa, instalada junto a sus ejemplos y referencias.

Los tableros existentes conservan su formato. Para actualizar desde v2.1.0, instalá el Manager de esta release, ejecutá `chuli --client codex update`, revisá la vista previa y repetí con `--apply`. Elegí `agy` o `claude` para el perfil correspondiente. Verificá el resultado con `doctor` para ese cliente. Para restaurar la instalación anterior del perfil, revisá `rollback` y aplicalo con `--apply`.
