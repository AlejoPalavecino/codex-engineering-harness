# Chuli 1.1.0 · Integraciones, Consola CRT y documentación visual

Esta versión incluye el asistente de integraciones, el diseño retro del Manager y documentación con diagramas. El perfil conserva seis especialistas y amplía su catálogo a 24 skills.

- **Integraciones voluntarias:** Context7, Engram, Exa, GitHub y Egolite, con requisitos y guías oficiales. La TUI y `chuli integrations` permiten revisar el estado, previsualizar, confirmar, comprobar y deshacer las conexiones propias. Conserva configuraciones existentes y referencia credenciales por variable de entorno. [PRs #52–#56](https://github.com/AlejoPalavecino/codex-engineering-harness/pull/56), issue #51.
- **Consola CRT:** PC y CHULI dibujados en texto, paleta verde fósforo/beige, explicación contextual, distribución adaptable y estados explícitos. Las vistas previas conservan el destino completo en el contenido desplazable. No requiere protocolos de imágenes ni nuevas fuentes.
- **Diagram Design 2.6:** skill completa fijada al commit `6a7f19fcc132b39b126bea90167679b46b14bcc4`, con sus 293 recursos originales y licencia MIT. Se activa cuando un diagrama mejora la explicación. No instala plugins ni dependencias opcionales.
- **README y marca:** logo retro, explicación de responsabilidades, agentes, skills y seguimiento, más diagramas de arquitectura y trabajo con fuentes HTML/SVG.

## Cómo actualizar

| Equipo | Nuevo Manager |
| --- | --- |
| Windows x64 | `chuli_v1.1.0_windows_amd64.zip` |
| Linux x64 | `chuli_v1.1.0_linux_amd64.tar.gz` |
| macOS ARM64 | `chuli_v1.1.0_darwin_arm64.tar.gz` |

El perfil es `chuli-profile-v1.1.0.zip`. Comprobá los cuatro paquetes con `SHA256SUMS.txt`.

**Desde tu TUI actual:** elegí instalar o actualizar desde la última release, revisá el destino y el plan y confirmá. Esto actualiza el perfil, incluidas las skills. Después abrí una sesión nueva de Codex.

**Para tener Consola CRT y el asistente:** cerrá el Manager, descargá el ejecutable de esta versión para tu equipo, extraelo y abrilo en lugar del anterior. La TUI anterior no reemplaza su propio ejecutable. No hace falta borrar tu perfil ni tus configuraciones.

Necesitás Python 3.11+ y PowerShell (`pwsh` en Linux/macOS). Engram y Egolite mantienen descarga y onboarding guiados; las cuentas y credenciales se configuran por separado. Configurar una conexión no acredita acceso efectivo a los datos.

## Evidencia y límites

Los paquetes oficiales se recuperan del CI del SHA final de main. El publicador comprueba versión, tag, archivos y SHA-256; las referencias al commit y a esa ejecución se agregan al publicar. No se suben ejecutables compilados localmente.

Las pruebas usan perfiles temporales y servidores MCP simulados: preservación, cancelación, vista previa vigente, reversión conservadora, symlinks/junctions, JSON/SSE, autenticación, timeout, redirecciones y ping. El diagnóstico remoto usa initialize y tools/list, sin tools/call. No se probaron proveedores con cuentas reales ni se modificaron memorias personales.

La TUI CRT cuenta con pruebas de ancho/altura de todas las pantallas en 40×24, 80×24 y 120×32 y un recorrido real en terminal Windows de 80×24. Eso no acredita apariencia en todos los emuladores ni terminales nativas Linux/macOS. Las campañas conductuales del perfil y comprensión humana siguen siendo evidencia separada.

La actualización y el rollback del perfil conservan las reglas existentes de personalización. Los registros de entrega y sus resultados concretos están en `odd/tasks/release-v1.1.0.md`; un estado pendiente no se declara verificado.
