# Chuli v0.3.0 — Checklist de lanzamiento

> Estado: preparación. No autoriza publicación. Depende de aprobar la arquitectura, implementar el aislamiento y superar las pruebas reales.

## Arquitectura y dependencias
- [ ] ADR-0001 aprobado.
- [ ] v0.2.1 integrado en main; decisión sobre tag/release registrada.
- [ ] CODEX_HOME aislado y login separado comprobados.
- [ ] Permission Profiles compatibles con la versión mínima declarada.
- [ ] Sin sandbox_mode/sandbox_workspace_write que anule los perfiles.
- [ ] Procesos principales separados por nivel de confianza.
- [ ] Worktrees independientes y lifecycle seguro.

## Protección de pruebas
- [ ] Tests aprobados congelados por commit y SHA-256.
- [ ] Shell no puede escribir, borrar ni renombrar tests congelados.
- [ ] apply_patch no puede modificar tests ni escalar permisos automáticamente.
- [ ] Subagentes heredan la política de implementation.
- [ ] Reviewer read-only.
- [ ] Verifier sobre copia temporal; candidato original intacto.

## Backend y plataformas
- [ ] Registrar versión Codex, SO, build y backend efectivo.
- [ ] Windows MXC o elevated pasa la suite.
- [ ] Unelevated no se declara compatible con deny-read.
- [ ] Linux/macOS superan sus propios probes antes de declararse soportados.
- [ ] Procesos hijos, traversal, enlaces y rutas denegadas probados.
- [ ] Red local deshabilitada por defecto; proxy probado si se habilita.
- [ ] MCP ausente por defecto y allowlist documentada.

## Integridad y release
- [ ] Instalación, actualización, reinstalación y rollback sin regresiones.
- [ ] CODEX_HOME personal intacto; sin copia de credenciales.
- [ ] TTP, evaluación y Manager siguen funcionando.
- [ ] CI completo y revisión independiente sobre SHA exacto.
- [ ] README, instalación, seguridad y changelog actualizados.
- [ ] VERSION 0.3.0, artefactos y SHA256SUMS verificados.
- [ ] Tag inmutable y release notes con límites reales.

No publicar si una sesión real modifica tests congelados, el backend no coincide con el perfil, una restricción crítica no puede probarse, una plataforma no completa su matriz o la evidencia no corresponde al commit publicado.
