# Identidad del producto

**Chuli** es un perfil personal de ingeniería para Codex. **Chuli Manager** es su instalador y gestor de versiones en terminal. La interfaz del usuario para programar es Codex CLI o el modo Codex local de la app de escritorio.

La comunicación del orquestador emplea español argentino claro. El idioma de cada entrega respeta al proyecto y a su audiencia. El nombre de cada skill importada conserva su identidad y atribución de origen. [Licencias y procedencia](../THIRD_PARTY_NOTICES.md).

## Identidad visual

La dirección del README toma la PC personal de fines de los ochenta y principios de los noventa: gabinete beige, monitor CRT, fósforo verde y letras pixeladas. El motivo conecta el trabajo en terminal con el perfil de ingeniería; no representa un fabricante de hardware.

El [logo de Chuli](../assets/brand/chuli-logo.png) es un PNG con transparencia, generado con la herramienta integrada de imágenes. Se conserva el [prompt de generación](../assets/brand/logo-prompt.txt) para revisar su procedencia y explorar futuras variantes. El archivo original tiene 2172×724 píxeles; el README lo muestra a una anchura menor sin alterar la imagen.

Usar el logo completo con sus proporciones y margen. Mantener instrucciones, requisitos, enlaces y nombres de comandos como texto accesible, en lugar de incrustarlos en ilustraciones. Los títulos numerados y el diagrama del README evocan un manual de computación; no son una salida real del Manager.
