# Diagram design

Read the [complete workflow](GUIDE.md) from this skill directory before creating, revising, importing or exporting a diagram. The guide contains the type selection tables, visual rules, examples, output checklist and export instructions. Resolve its links from this directory.

1. Resolve the project profile or style guide before drawing. Follow the first-time setup gate when the project still uses default tokens.
2. Select the semantic pattern and visual type for the information being communicated. Read the matching reference and choose a template from the guide.
3. Apply the style, spacing, labeling and accessibility checks. Follow the import workflow for existing artifacts.
4. Use the pre-output checklist and the output procedure for the requested format before delivering the diagram.
